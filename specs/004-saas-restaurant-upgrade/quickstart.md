# Quickstart: Restaurant SaaS Comprehensive Upgrade

**Branch**: `004-saas-restaurant-upgrade`

---

## Prerequisites

- Node.js 20+
- PostgreSQL 15+ (local or Supabase)
- Existing `.env` with all current variables configured

## New Environment Variables

Add these to your `.env`:

```env
# Cron security
CRON_SECRET=generate-with-openssl-rand-hex-32

# 2FA (uses AUTH_SECRET as encryption key — no new var needed)

# Talabat (per-tenant, stored in DB — no env var needed)

# SMS/Tracking notifications (optional for this phase)
TWILIO_ACCOUNT_SID=
TWILIO_AUTH_TOKEN=
TWILIO_FROM_NUMBER=
```

## Database Migration

```bash
# This project uses db push (no migration history). After pulling the branch:
npx prisma db push

# Verify schema is in sync
npx prisma validate
```

> **Note**: `prisma db push` was used instead of `migrate dev` because the database was not previously managed by Prisma Migrate. All new columns (2FA fields, modifiers, shifts, purchase orders, etc.) are applied via `db push`.

## Development Workflow

### Testing QR Self-Ordering Locally
1. Start dev server: `npm run dev`
2. Create a table in the dashboard
3. Navigate to `/dashboard/tables` → generate QR for a table
4. Open the QR URL on mobile or in an incognito window
5. Place a test order — verify it appears in `/captain`

### Testing Offline Mode
1. Open `/cashier` in Chrome
2. DevTools → Network tab → set to "Offline"
3. Create an order — observe the "Offline" banner and local queue
4. Set network back to "Online" — watch orders sync

### Testing 2FA Setup
1. Log in as ADMIN
2. Navigate to `/dashboard/settings` → Security tab
3. Click "تفعيل المصادقة الثنائية"
4. Scan QR with Google Authenticator
5. Enter 6-digit code to confirm
6. Log out and log back in — verify TOTP prompt appears

### Testing Password Reset
1. Navigate to `/login` → "نسيت كلمة المرور"
2. Enter a registered user's email
3. Check the email inbox (Resend dashboard in dev mode)
4. Click the link (valid 30 minutes)
5. Set new password

### Testing Talabat Webhooks Locally
```bash
# Simulate a Talabat inbound order
curl -X POST http://localhost:3000/api/webhooks/talabat \
  -H "Content-Type: application/json" \
  -H "X-Talabat-Signature: $(echo -n '{"orderId":"TAL-TEST-001"}' | openssl dgst -sha256 -hmac YOUR_WEBHOOK_SECRET -hex | cut -d' ' -f2)" \
  -d '{"orderId":"TAL-TEST-001","restaurantId":"STORE_ID","orderType":"DELIVERY",...}'
```

### Testing Inventory Expiry Alerts
```bash
# Trigger the cron manually
curl -X GET http://localhost:3000/api/cron/expiry-check \
  -H "Authorization: Bearer $CRON_SECRET"
```
